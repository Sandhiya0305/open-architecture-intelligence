# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues or discussions. Use GitHub's private vulnerability reporting or security advisory feature for this repository. Include the affected commit or version, impact, reproduction steps and any suggested mitigation.

Please do not include credentials, personal data or production secrets in a report. Security reports are reviewed by the repository maintainer; no fixed response-time commitment is made.

## Supported versions

Security fixes are considered for the current default branch. Older releases are not guaranteed to receive updates.
